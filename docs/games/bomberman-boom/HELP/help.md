## PAGE 3 / 12 — Basic Game Rules

- MINIMUM BET IS 80 CREDITS.
- ALL WINS ARE SHOWN IN CREDITS EXCEPT **GRAND JACKPOT**, **MEGA**, **MAJOR**, **MINOR** AND **MINI** AMOUNTS SHOWN.
- THE CHANCE OF WINNING GRAND JACKPOT WILL CHANGE WITH THE DENOMINATION (IF MULTI DENOMINATION IS AVAILABLE).
- THE CHANCE OF WINNING GRAND JACKPOT WILL CHANGE WITH THE CREDITS BET.
- **THE CHANCE OF ACHIEVING PROGRESSIVE AWARD(S) IMPROVES AS THE WAGER IS INCREASED.**
- **GRAND JACKPOT MAY BE AWARDED RANDOMLY AT THE END OF ANY PRIMARY GAME.**
- THE VALUES FOR MEGA, MAJOR, MINOR AND MINI WILL SCALE WITH THE DENOMINATION (IF MULTI DENOMINATION IS AVAILABLE).
- THE VALUES FOR MEGA, MAJOR, MINOR AND MINI WILL SCALE WITH THE CREDITS BET.
- AFTER ALL REELS STOP DURING THE PRIMARY GAME, IF REEL 2, 3 OR 4 RE-SPINS AND [BOMBER GAME], [FREE GAME] OR [JACKPOT FEATURE] APPEARS, THEN BOMBER GAME FEATURE, FREE GAME FEATURE OR JACKPOT FEATURE WILL BE TRIGGERED RESPECTIVELY.
- AFTER ALL REELS STOP DURING THE PRIMARY GAME, IF ANY 3 SYMBOLS ON REELS 2, 3 AND 4 ARE REPLACED WITH 3 [BOMBER GAME], 3 [FREE GAME] OR 3 [JACKPOT FEATURE], THEN BOMBER GAME FEATURE, FREE GAME FEATURE OR JACKPOT FEATURE WILL BE TRIGGERED RESPECTIVELY.
- THE RE-SPIN OR THE SYMBOL REPLACEMENT WILL NEVER REDUCE THE VALUE OF THE TOTAL SCREEN WIN.
- MALFUNCTION VOIDS ALL PAYS AND PLAYS.
- ALL WINS PAID BY MACHINE OR ATTENDANT.
- A PLAYER CANNOT INFLUENCE THE RESULT OF A GAME BY STOPPING THE REEL SPINS.
- PLAYER IS RESPONSIBLE FOR ENSURING CORRECT CREDITS ARE REGISTERED BEFORE PLAY.
- THE GAME DISPLAY DOES NOT INDICATE HOW CLOSE YOU WERE TO WINNING, AND CANNOT NECESSARILY BE USED TO DETERMINE YOUR CHANCES OF WINNING OR LOSING IF YOU CONTINUE TO PLAY.

## PAGE 4 / 12 — Feature Game Rules：BOMBER GAME FEATURE

- WHENEVER 1 OR 2 [BOMBER GAME] APPEAR ON REEL 2, 3 OR 4 THERE IS A CHANCE THE BOMBER GAME FEATURE MAY BE TRIGGERED.
- 3 [BOMBER GAME] ON REELS 2, 3 AND 4 WILL TRIGGER THE BOMBER GAME FEATURE.
- **5 SPINS ARE AWARDED.**
- THE BONUS SCREEN APPEARS.
- THE BONUS SCREEN IS COMPOSED OF **25 REELS**. ALL REELS ARE INDIVIDUAL SPINNING REELS.
- （圖）5×5 盤面，最上一排標 **TOP AREA**、最下一排標 **BOTTOM AREA**
- AT THE START OF THE BOMBER GAME FEATURE, THERE ARE [BRICK] ON ALL REELS WITHIN THE TOP AREA AND BOTTOM AREA.
- REELS COVERED WITH [BRICK] ARE NOT ACTIVE.
- THE BOMBER GAME FEATURE CONTAINS FOUR SETS OF REEL TYPES.

| REEL TYPE | SYMBOLS |
|---|---|
| CREDIT PRIZE REEL | [COIN] AND BLANK |
| BONUS PRIZE REEL | [MEGA]、[MAJOR]、[MINOR]、[MINI] AND BLANK |
| BOMB REEL | [BOMB] AND BLANK |
| DOUBLE BOMB REEL | [2x BOMB] AND BLANK |

- AT THE START OF EACH SPIN, THE CREDIT PRIZE REEL OR BONUS PRIZE REEL IS RANDOMLY SELECTED.
- AT THE START OF EACH SPIN, THE BOMB REEL RANDOMLY APPEARS ON AT LEAST ONE POSITION.
- THE NUMBER OF BOMB REELS ACTIVE, ON THE BONUS SCREEN PER SPIN CORRESPONDS TO THE NUMBER OF [BOMB] DISPLAYED IN BOMB REEL COUNTER.
- AT THE START OF EACH SPIN, THE DOUBLE BOMB REEL MAY RANDOMLY APPEAR AT ONLY 1 POSITION INSTEAD OF A BOMB REEL ON THE BONUS SCREEN.
- AT THE START OF EACH SPIN, A BOMB REEL MAY BE REPLACED WITH A DOUBLE BOMB REEL.
- ONLY CREDIT PRIZE REEL CAN APPEAR IN THE CENTER POSITION OF EACH COLUMN ON THE FIRST SPIN OF THE BOMBER GAME FEATURE.

## PAGE 5 / 12 — BOMBER GAME FEATURE（續）

- DURING THE BOMBER GAME FEATURE IF 1 OR MORE [COIN]、[MEGA]、[MAJOR]、[MINOR]、[MINI]、[BOMB] AND/OR [2x] APPEAR, **AN ADDITIONAL SPIN IS AWARDED.**
- DURING THE BOMBER GAME FEATURE IF 1 OR MORE [COIN]、[MEGA]、[MAJOR]、[MINOR] AND/OR [MINI] APPEAR, **THE SYMBOLS ARE HELD.**
- CREDIT PRIZES SHOWN ON EACH [COIN] ARE **40, 60, 80, 100, 120 OR 200 MULTIPLIED BY THE BET PER LINE**.
- BONUS PRIZES SHOWN ON EACH [LOCKED BONUS] ARE MEGA, MAJOR, MINOR OR MINI.
- **UP TO 3 [LOCKED BONUS] CAN BE HELD ON THE BONUS SCREEN.**
- THE [LOCKED BONUS] BONUS PRIZES CANNOT BE AWARDED.
- IF [BOMB] OR [2x] APPEAR ON A REEL, THE INITIAL BLAST AREA IS AS SHOWN BELOW：（圖）**十字形，上下左右各 1 格**
- IF THERE IS A [LOCKED BONUS] WITHIN THE BLAST AREA, [LOCKED BONUS] WILL BE UNLOCKED AND CHANGE TO [UNLOCKED BONUS].
- **PRIZE SYMBOLS**：[COIN]、[MEGA]、[MAJOR]、[MINOR]、[MINI]
- IF THERE IS A PRIZE SYMBOL ON A POSITION IN THE BLAST AREA WHERE [BOMB] APPEARS, THE PRIZE SYMBOL IS ADDED AND COLLECTED IN THAT POSITION.
- IF THERE IS A PRIZE SYMBOL ON A POSITION IN THE BLAST AREA WHERE [2x] APPEARS, THE PRIZE SYMBOLS ARE FIRST MULTIPLIED BY 2, THEN ADDED AND COLLECTED IN THAT POSITION.
- IF THERE IS A PRIZE SYMBOL ON A POSITION WHERE THE BLAST AREAS INTERSECT, THE INTERSECTING PRIZE SYMBOL IS ADDED AND COLLECTED ON EACH [BOMB] OR [2x] POSITION AT THE SAME TIME.

## PAGE 6 / 12 — BOMBER GAME FEATURE（續）

- IF [BRICK] IS IN THE BLAST AREA WHEN [BOMB] OR [2x] APPEARS, [BRICK] EXPLODES AND REVEALS ONE OF THE FOLLOWING SYMBOLS IN THAT POSITION：[FIRE]、[BOMB+]、[+1 SPIN]、[MEGA]、[MAJOR]、[MINOR] OR [MINI].
- IF A [FIRE] IS REVEALED, **BLAST AREA EXPANDS 1 POSITION IN EACH HORIZONTAL & VERTICAL DIRECTION.**
- **UP TO 3 MORE [FIRE] CAN BE REVEALED** DURING THE BOMBER GAME FEATURE.
- （圖）**EXPAND BLAST AREA**：十字形共 4 階（初始→+1→+2→+3）
- THE BLAST AREA NEVER EXTENDS BEYOND THE [BRICK] TO THE ADJACENT REEL.
- IF A [BOMB+] IS REVEALED, **AN ADDITIONAL BOMB REEL IS ADDED**。**UP TO 2 MORE [BOMB+] CAN BE REVEALED** DURING THE BOMBER GAME FEATURE.
- IF A [+1 SPIN] IS REVEALED, **AN ADDITIONAL SPIN IS AWARDED**。**UP TO 3 [+1 SPIN] CAN BE REVEALED** DURING THE BOMBER GAME FEATURE.
- BONUS PRIZES SHOWN ON EACH [UNLOCKED BONUS] CAN ONLY BE MEGA, MAJOR, MINOR OR MINI。**UP TO 2 [UNLOCKED BONUS] CAN BE REVEALED** DURING THE BOMBER GAME FEATURE.
- IF A [UNLOCKED BONUS] IS REVEALED, THE BONUS PRIZE SHOWN ON [UNLOCKED BONUS] IN THE BLAST AREA IS ADDED AND COLLECTED IN THAT POSITION.
- **THE BOMBER GAME FEATURE ENDS WHEN THE NUMBER OF SPINS REMAINING IS 0.**
- AT THE END OF THE BOMBER GAME FEATURE, ALL CREDIT PRIZES APPEARING ON [COIN] WILL BE AWARDED.
- DIFFERENT REELS ARE USED DURING THE BOMBER GAME FEATURE.
- CREDITS BET ARE THE SAME AS THE GAME THAT TRIGGERED THE BOMBER GAME FEATURE.

## PAGE 7 / 12 — Feature Game Rules：FREE GAME FEATURE

- WHENEVER 1 OR 2 [FREE GAME] APPEAR ON REEL 2, 3 OR 4 THERE IS A CHANCE THE FREE GAME FEATURE MAY BE TRIGGERED.
- 3 [FREE GAME] ON REELS 2, 3 AND 4 WILL TRIGGER THE FREE GAME FEATURE.
- **5 FREE GAMES ARE AWARDED.**
- [PINK BOMBERMAN] RANDOMLY APPEARS ON REELS 2, 3 AND 4 ONLY DURING THE FREE GAME FEATURE.
- DURING THE FREE GAME FEATURE IF [PINK BOMBERMAN] APPEARS ON REEL 2, 3 OR 4, IT WILL CHANGE THE ENTIRE REEL TO ONE OF THE FOLLOWING SYMBOLS：[BOMBERMAN 全軸]、[2x 全軸]、[3x 全軸] OR [5x 全軸].
- IF [GOLD BOMB] RANDOMLY LANDS ON REEL 2, 3 OR 4 DURING THE REEL SPIN, IT WILL CHANGE THE ENTIRE REEL TO ONE OF THE FOLLOWING SYMBOLS：[2x 全軸]、[3x 全軸] OR [5x 全軸].
- [GOLD BOMB] CAN LAND ON REELS 2, 3 AND 4 DURING EACH REEL SPIN PER FREE GAME.
- IF [GOLD BOMB] RANDOMLY LANDS ON [BOMBERMAN 全軸] WITHIN REELS 2, 3 AND 4 AFTER THE REEL SPIN, THE [BOMBERMAN 全軸] WILL CHANGE TO ONE OF THE FOLLOWING SYMBOLS：[2x 全軸]、[3x 全軸] OR [5x 全軸].
- ONLY 1 [GOLD BOMB] CAN LAND ON [BOMBERMAN 全軸] WITHIN REELS 2, 3 AND 4 AFTER THE REEL SPIN PER FREE GAME.
- IF [GOLD BOMB] LANDS ON REEL 2, 3 OR 4 DURING THE REEL SPIN, [GOLD BOMB] WILL NOT APPEAR AFTER THE REEL SPIN PER FREE GAME.
- [BOMBERMAN 全軸]、[2x]、[3x] AND [5x] SUBSTITUTE FOR ALL PAY TABLE SYMBOLS EXCEPT [FREE GAME]、[BOMBER GAME] AND [JACKPOT FEATURE].

## PAGE 8 / 12 — FREE GAME FEATURE（乘倍組合）

- [5x] OR [3x] CAN ONLY APPEAR ONCE ON REELS 2, 3 AND 4 EACH FREE GAME.
- [5x] AND [3x] CANNOT APPEAR AT THE SAME TIME ON REELS 2, 3 AND 4.
- IF A [2x] SUBSTITUTES IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **2**.
- IF A [3x] SUBSTITUTES IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **3**.
- IF A [5x] SUBSTITUTES IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **5**.
- IF TWO [2x] SUBSTITUTE IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **4**.
- IF THREE [2x] SUBSTITUTE IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **8**.

## PAGE 9 / 12 — FREE GAME FEATURE（乘倍組合續）

- IF ONE [2x] AND ONE [3x] SUBSTITUTE IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **6**.
- IF ONE [2x] AND ONE [5x] SUBSTITUTE IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **10**.
- IF TWO [2x] AND ONE [3x] SUBSTITUTE IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **12**.
- IF TWO [2x] AND ONE [5x] SUBSTITUTE IN A WINNING COMBINATION, THE PAY FOR THAT WIN WILL BE MULTIPLIED BY **20**.
- **TOTAL MULTIPLIER CAN BE UP TO 20X EACH FREE GAME.**
- **ADDITIONAL FREE GAMES CAN BE WON DURING THE FREE GAME FEATURE.**
- **THE BOMBER GAME FEATURE AND JACKPOT FEATURE ARE AVAILABLE DURING THE FREE GAME FEATURE.**
- DIFFERENT REELS ARE USED DURING THE FREE GAME FEATURE.
- CREDITS BET AND LINES PLAYED ARE THE SAME AS THE GAME THAT TRIGGERED THE FEATURE.

## PAGE 10 / 12 — Feature Game Rules：JACKPOT FEATURE

- WHENEVER 1 OR 2 [JACKPOT FEATURE] APPEAR ON REEL 2, 3 OR 4 THERE IS A CHANCE THE JACKPOT FEATURE MAY BE TRIGGERED.
- 3 [JACKPOT FEATURE] ON REELS 2, 3 AND 4 WILL TRIGGER THE JACKPOT FEATURE.
- IF THE JACKPOT FEATURE IS TRIGGERED, **18 [EGG] WILL APPEAR FOR SELECTION.**
- TOUCH A [EGG] TO REVEAL ONE OF THE FOLLOWING SYMBOLS：**GRAND JACKPOT、MEGA、MAJOR、MINOR、MINI OR [BOMBER GAME]**.
- WHEN 3 MATCHING SYMBOLS HAVE BEEN REVEALED, THE CORRESPONDING SYMBOL WIN OR SYMBOL TRIGGER WILL BE AWARDED AND THE FEATURE ENDS.
- PLAYER SELECTION DOES NOT AFFECT THE OUTCOME OF THE GAME.

| 結果 | SYMBOL |
|---|---|
| GRAND JACKPOT WIN | GRAND JACKPOT ×3 |
| MEGA WIN | MEGA ×3 |
| MAJOR WIN | MAJOR ×3 |
| MINOR WIN | MINOR ×3 |
| MINI WIN | MINI ×3 |
| BOMBER GAME FEATURE IS TRIGGERED | BOMBER GAME ×3 |

- THERE IS NO PAYOUT FOR TRIGGERING THE BOMBER GAME FEATURE DURING THE JACKPOT FEATURE.
- WHEN 3 MATCHING SYMBOLS HAVE BEEN REVEALED, THE LAST SYMBOL REVEALED MAY CHANGE TO OTHER SYMBOL TO WIN FOR OTHER 3 MATCHING SYMBOLS.
- IF THE SYMBOL CHANGES, THE CORRESPONDING SYMBOL WIN IS ONLY AWARDED FOR THE LAST 3 MATCHING SYMBOLS.
- THE SYMBOL CHANGE WILL NEVER REDUCE THE VALUE OF THE TOTAL SCREEN WIN.
